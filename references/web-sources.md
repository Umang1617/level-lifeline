# Web Guide Sources Reference

## Chrome Search Instructions
Open Chrome inside BlueStacks. Search using this query format:
`[game name] [problem] walkthrough guide [current year]`

## Trusted Sites to Prioritize (in order)
1. Game-specific wikis - Fandom, Gamepedia
2. Dedicated guide sites - ign.com, gamepur.com, gamesradar.com, pocket-tactics.com, gamefaqs.gamespot.com
3. Gaming news sites with guides section - sportskeeda.com, polygon.com
4. Official game website or developer blog

## Walkthrough Section Keywords
Once a page loads, scroll down to find sections with these headings:
- Walkthrough
- Strategy
- How to Beat
- Steps
- Attack Guide
- Tips and Tricks
- Best Strategy
- Solution

Scroll past ads, intro paragraphs, and video embeds to reach the written walkthrough section directly.

## Quality Signals
- Guide published or updated within last 12 months
- Has numbered or bulleted steps (not just generic tips)
- Mentions current patch, season, or update
- Has specific item, troop, or character recommendations

## What to Extract
- Core strategy in 3-5 concrete steps
- Specific items, troops, characters, or settings required
- Any "avoid this mistake" warnings
- Full page URL
- Site name
